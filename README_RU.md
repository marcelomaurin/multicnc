## Единая платформа для проектирования, моделирования и производства

**MultiCNC** — открытый комплекс цифрового производства, объединяющий **проектирование, подготовку, моделирование и управление оборудованием** в одной экосистеме.

Проект задуман не просто как программа передачи G-code. Его цель — объединить **CNC-фрезеры, CNC-лазеры, 3D-печать, электронику, печатные платы, электромеханическую сборку и физическое моделирование**.

> **Одна идея, несколько процессов, одна среда.**

### Видение проекта

```text
ИДЕЯ → ПРОЕКТ → МОДЕЛИРОВАНИЕ → ПОДГОТОВКА → ПРОВЕРКА → ИЗГОТОВЛЕНИЕ
```

### Основные приложения

- **MultiCNC:** управление оборудованием
- **MultiSuite:** единая точка входа
- **MultiCAD:** геометрия и проектирование
- **MultiCAM:** подготовка траекторий
- **MultiSlicer:** подготовка 3D-печати
- **MultiPCB / MakePCB / LaserPCB:** проектирование и изготовление PCB (MakePCB: плата с нуля в стиле PCB Wizard, Gerber + Excellon для LaserPCB)
- **RouterPCB:** фрезеровка PCB на CNC Router (изоляция V-фрезой, сверловка, обрезка контура с перемычками, выравнивание по зондированию) из папки Gerber + Excellon MakePCB. См. [routerpcb/README.md](routerpcb/README.md)
- **MakeRouter** *(первая версия 2,5D)*: проектирование и фрезеровка деталей из дерева на CNC Router (чертёж, рельеф, траектории, симуляция) в стиле Aspire; G-code с виртуальным нулём, который выставляет MultiCNC. См. [makerouter/README.md](makerouter/README.md)
- **MultiAssembly:** интеграция механики и электроники
- **MultiPhysics:** многодоменное физическое моделирование

Для CNC-лазера предусмотрена проверка рабочей области перед запуском с помощью обхода контура, а также настройки мощности, скорости, числа проходов, типа операции и подачи воздуха.

**MultiPhysics** позволяет изучать поведение проекта до реального изготовления. Искусственный интеллект развивается как вспомогательный слой для анализа, подготовки, диагностики и подсказок оператору.

MultiCNC предназначен для **мейкеров, студентов, преподавателей, технических учебных заведений, университетов, FabLab, лабораторий, исследователей, разработчиков, специалистов по автоматизации и небольших мастерских**.

Проект имеет **открытый исходный код и постоянно развивается**.
