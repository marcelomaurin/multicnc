# MultiSuite 0.01 (Build 001)

| Arquivo | Plataforma | Uso |
|---|---|---|
| setup_001.exe | Windows 10/11 x64 | Instalador Inno Setup com selecao de ferramentas ou instalacao completa |
| MultiSuite-0.01-linux-x86_64.tar.xz | Linux x86_64 | Pacote com instalador modular install.sh |
| MultiSuite-0.01-linux-aarch64.tar.xz | Linux ARM 64 bits (Raspberry Pi 3/4/5 64b) | Pacote com instalador modular install.sh |
| MultiSuite-0.01-linux-armhf.tar.xz | Linux ARM 32 bits (Raspberry Pi 32b) | Pacote com instalador modular install.sh |

## Recursos do Instalador:
- Permite escolher individualmente as ferramentas a instalar ou instalar tudo.
- Ferramentas inclusas: MultiSuite, MultiCNC, MultiCAD, MultiPCB, MultiAssembly, MultiPhysics, MultiCAM, MultiSlicer, LaserPCB, LaserArt e Central de Testes.
- Criacao de atalhos e associacao de arquivos (.msuite).

Conferir integridade dos arquivos com:
sha256sum -c SHA256SUMS
