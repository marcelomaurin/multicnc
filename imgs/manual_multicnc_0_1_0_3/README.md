# MultiCNC 0.1.0.3 - capturas do manual

Capturas de 12/10/2026, renderizadas diretamente pelos formulários LCL das fontes
do MultiCNC, conferidas no commit 687756e. Os exemplos são demonstrativos.
A configuração de equipamentos foi isolada e somente o simulador local foi
conectado; nenhuma controladora física foi acionada.

As imagens completas têm 1360 × 960 pixels e preservam a interface. O PDF usa
também recortes para tornar os controles legíveis, sem modificar os valores ou
as mensagens. Os nomes em inglês e a codificação de alguns rótulos refletem o
estado atual da tela.
