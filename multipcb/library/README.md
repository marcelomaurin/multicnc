# Biblioteca MultiPCB
Catálogo nativo extensível. Cada item usa ID estável, família, símbolo, footprint e pinagem.
Famílias iniciais: Arduino, ESP, RP2040, STM32, AVR, PIC, passivos, semicondutores, alimentação, conectores, sensores, displays e drivers.
A biblioteca pode crescer sem alterar o núcleo.
