# MultiPCB

Editor de esquemáticos e PCB integrado ao ecossistema MultiCNC.

## Objetivo
Projetar circuitos com foco em Arduino, ESP32, RP2040, STM32, AVR, PIC, sensores, módulos e componentes eletrônicos; validar ERC/DRC e preparar arquivos de fabricação.

## Módulos
- Core EDA: projeto, componente, pino, net, símbolo e footprint
- Biblioteca: Arduino/MCU + componentes
- ERC/DRC
- Editor Lazarus
- Exportadores: Gerber, Excellon e G-code
- Integração futura com MultiCNC
- Assistência opcional pela suíte CHATGPT

A IA auxilia o projeto, mas ERC/DRC e regras elétricas são determinísticos.
