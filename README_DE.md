## Eine integrierte Plattform zum Entwerfen, Simulieren und Fertigen

**MultiCNC** ist eine offene Suite für digitale Fertigung, die **Entwurf, Vorbereitung, Simulation und Maschinenbedienung** in einer gemeinsamen Umgebung verbindet.

Das Projekt geht über einen einfachen G-code-Sender hinaus. Ziel ist die Integration von **CNC-Fräsen, CNC-Lasern, 3D-Druck, Elektronik, Leiterplatten, elektromechanischen Baugruppen und physikalischer Simulation**.

> **Eine Idee, mehrere Verfahren, eine Umgebung.**

### Vision

MultiCNC verbindet die Schritte der digitalen Fertigung:

```text
IDEE → ENTWURF → SIMULATION → VORBEREITUNG → VALIDIERUNG → FERTIGUNG
```

### Hauptanwendungen

- **MultiCNC:** Maschinenbedienung und -steuerung
- **MultiSuite:** zentraler Einstieg in die Suite
- **MultiCAD:** Geometrie und Konstruktion
- **MultiCAM:** Werkzeugweg- und Fertigungsvorbereitung
- **MultiSlicer:** Vorbereitung für den 3D-Druck
- **MultiPCB / MakePCB / LaserPCB:** Leiterplattenentwurf und -fertigung (MakePCB: Platine von Grund auf, im Stil von PCB Wizard, Gerber + Excellon für LaserPCB)
- **MultiAssembly:** mechanisch-elektronische Integration
- **MultiPhysics:** multidomänenübergreifende physikalische Simulation

Für CNC-Laser umfasst das Konzept eine Kontur-/Rahmenfunktion zur Prüfung der tatsächlichen Arbeitsfläche vor dem Start sowie Einstellungen für Leistung, Geschwindigkeit, Durchgänge, Betriebsart und Air Assist.

**MultiPhysics** ermöglicht die Untersuchung eines Projekts vor der realen Fertigung. KI wird als Assistenz für Analyse, Vorbereitung, Diagnose und Bedienerunterstützung integriert.

MultiCNC richtet sich an **Maker, Studierende, Lehrkräfte, technische Schulen, Universitäten, FabLabs, Labore, Forschende, Entwickler, Automatisierungsfachleute und kleine Werkstätten**.

Das Projekt ist **Open Source und wird kontinuierlich weiterentwickelt**.
